# Котельная — Boiler Panel v0.9.0

Самостоятельная панель **GUITION JC4880P443C_I_W / ESP32-P4 + ESP32-C6**, экран 480×800. Репозиторий `DeadSoulf/boiler_room` — источник кода и версий. Не смешивать с другими проектами отопителей или ESP32-S3.

## Новое в v0.9.0

- В карточке «Топливо» на главной — небольшая температура и канистра. Отдельная нижняя кнопка уровня удалена. Полная / половина / пустая с «!»; неизвестные/устаревшие данные не заменяются полным баком.
- **Сопряжение начинается в браузере:** нажмите «Сопряжение». На дисплее автоматически открывается главная и появляется шестизначный код **слева от часов**. Экран при необходимости просыпается. После успешного ввода код исчезает; также исчезает при отмене или через 2 минуты. Раздел «Веб-доступ» на физическом дисплее удалён.
- Веб-интерфейс обновлён: Главная, Оборудование, Топливо, Настройки. Wi-Fi/BLE, часы, экран, датчики, Home Assistant и сервис сгруппированы внутри настроек. Технические сведения и опасные операции раскрываются отдельно.

Код сопряжения виден только на физическом дисплее, не передаётся в API или MQTT. Сессия длится час. Защита от повторных запросов/перебора не заменяет защищённую сеть: HTTP и MQTT этой версии **без TLS, только доверенная LAN, без проброса портов**.

## Герконы, датчики и управление

Для заданной пользователем схемы оба геркона настраиваются как **NC**: оба разомкнуты → полная; замкнут только верхний → половина; оба замкнуты → пустая с «!»; замкнут только нижний → ошибка уровня. Существующий режим NO сохранён для обратной полярности. Пины и NVS автоматически не меняются. Обрыв обычного несупервизируемого контакта неотличим от размыкания — не использовать этот индикатор как единственную защиту оборудования.

Доступны реальные входы DS18B20 и герконов на проверенных JP1 GPIO, четыре температурных и два уровневых канала. Пока реальные датчики не подключены/не испытаны. Нет команд силового управления котлами, насосами, реле и подогревом. Modbus/MQTT в конфигураторе входов ещё не являются работающими драйверами удалённых показаний.

Home Assistant получает 12 сущностей через MQTT Discovery; по умолчанию модуль выключен. Реальное подключение к брокеру ещё не проверялось. Веб-форма принимает пароль только локально и не возвращает его через API.
