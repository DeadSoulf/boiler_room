# Котельная — Boiler Panel v0.6.2

Проект самостоятельной сенсорной панели GUITION JC4880P443C_I_W: ESP32-P4 rev1.3, ESP32-C6 для Wi-Fi/BLE, дисплей 480×800 с LVGL. Разработка и версии ведутся через GitHub. Прошивки других отопителей и релейных блоков сюда не входят.

## Обновление v0.6.2

Удалены неиспользуемый код DEMO и тесты симулятора. Семь реальных устройств отображаются только как «Контроллер не подключён»; физические команды не добавлены. Исправлены тесты безопасности веб-интерфейса и microSD. Драйверы датчиков, GPIO, NVS, Wi-Fi/C6 и работа с картой памяти остались без функциональных изменений.

## Что работает на панели

- **Дисплей:** главная с четырьмя температурами (котельная, улица, теплоноситель, топливо), история, уровень топлива, оборудование, Wi-Fi/BLE и сервис. Навигация свайпами, часы в шапке, пробуждение касанием, таймер подсветки. Пункт «Дата и время» отсутствует в настройках физического дисплея — время настраивается из веб-панели. «Проверка символов» удалена.
- **Wi-Fi:** подключение через ESP32-C6 ESP-Hosted, работающий поиск сетей и повторное подключение, IP, NTP и BLE-сканирование. Текущая версия радио P4/C6 — 2.9.6, переустановка не требуется.
- **Веб-интерфейс:** локальный HTTP на ESP32-P4. Вкладки «Главная», «Оборудование», «Топливо», «Настройки», «Устройства», «Сервис». Сохранение настроек только с действующим токеном сопряжения, который выдаётся после ввода кода с физического дисплея. Для доверенной LAN; нельзя пробрасывать HTTP порт в интернет.
- **Реальные входы v0.6.1:** DS18B20 через аппаратный RMT/OneWire (по одному на GPIO), два геркона топлива (NO/NC с антидребезгом). Только внешние GPIO, подтверждённые для JP1. Датчики должны быть физически подключены и назначены пользователем в веб-разделе «Устройства». Если датчика нет, показания не выдумываются.
- **Хранилище microSD:** поддержка монтирования, общий/свободный объём, ограниченные журналы событий и реальных показаний. Автоматического форматирования нет. Ручное форматирование FAT из веб-панели требует физического подтверждения на дисплее.
- **Подключения:** шесть каналов (4 температуры + 2 геркона). Назначения сохраняются в двух NVS-слотах с контрольной суммой, валидацией GPIO и возможностью отката. Modbus RTU/RS-485 и MQTT пока доступны только как определения в конфигураторе — реальные драйверы этих источников ещё не включены.

## Ограничения безопасности

- Реальных контроллеров бойлера косвенного нагрева, электрокотла (3 контура), дизельного отопителя и подогрева топлива пока нет. В интерфейсе честно указано «Не подключено». **Команд управления нагревом, насосами, реле и демонстрационных функций нет.**
- GPIO35 — кнопка BOOT; GPIO дисплея, GT911, ESP32-C6/SDIO, microSD, аудио и RS-485 не доступны для датчиков. Разрешены только 11 наружных JP1 GPIO, список и расположение см. [реальные датчики и распиновка](docs/real-sensors-v061.md).
- Герконная схема не обнаруживает обрыв кабеля и не может служить единственной защитой топлива. DS18B20 требует 3,3 В и внешнюю подтяжку 4,7 кОм. Электрическую проводку и реальные измерения нужно проверить после подключения датчиков.
- Физическое считывание DS18B20 на этой панели **ещё не подтверждено датчиком**: без назначений входы не включаются. Результат сборки не заменяет аппаратное испытание.

## Результат последней аппаратной проверки (3 ноября 2026)

На реальную панель через Asus / COM3 (115200 бод) **установлена v0.6.2**. Сборка ESP32-P4 завершилась `SUCCESS`. Полная резервная копия старого app0 и загрузочных метаданных сделана до записи.

Первая автоматическая проверка после записи оборвалась при чтении по USB. Повторное независимое чтение **всех 1 608 224 байт** подтвердило побайтное совпадение с `firmware.bin`. Таблица разделов и OTA повторно сверены с резервными копиями. После перезапуска:

- `GET /`, `GET /health` и `GET /api/status` вернули HTTP 200; `version=v0.6.2`, Wi-Fi connected.
- microSD: `mounted=true`, `logging=true`, форматирование не запускалось.
- Шесть каналов, `revision=0`, `drivers_active=false`: **датчики ещё не подключены и GPIO не назначены**.
- Веб-интерфейс не содержит старых DEMO-действий; силовые выходы отключены.
- NVS, загрузчик, таблица разделов, OTA и ESP32-C6 установщиком не записывались.

[Полный проверяемый отчёт об установке v0.6.2](docs/verification/v0.6.2-hardware-2026-11-03.md).

**CI:** отдельные проверки датчиков, конфигурации, веба, microSD и Windows launcher успешны. Старый общий native CI остаётся красным из-за устаревших Wi-Fi host-заглушек `esp_wifi.h`; этот долг не следует путать с успешно проверенной локальной сборкой P4.
