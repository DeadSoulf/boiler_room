# Котельная — Boiler Panel v0.10.4

## v0.10.4: дата под часами на главной

В правом верхнем углу физической панели под временем показана местная дата в формате **ДД.ММ.ГГГГ**. Шестизначный код сопряжения сохраняет отдельную область слева. Обе строки используют один момент времени и настроенный часовой пояс; до установки времени показаны прочерки. На остальных страницах остаётся кнопка «Домой».

Версия готовится и проверяется для GitHub OTA. Публикация и установка v0.10.4 пока не подтверждены; последняя принятая по сети версия устройства — v0.10.1.

## v0.10.3: стабильный экран обновления

Физическая страница обновления сохраняет существующие элементы при изменениях уровня сигнала Wi-Fi. Текст загрузки и состояние кнопок меняются только при изменении отображаемых значений: неизменная страница больше не перерисовывается и не запускает заново анимацию отключённых кнопок каждые 100 мс. Прогресс, отмена, доступность подключения и подтверждение конкретной версии продолжают работать.

**[v0.10.3 опубликована для GitHub OTA](https://github.com/DeadSoulf/boiler_room/releases/tag/v0.10.3).** Настоящий LVGL 8.3.11 прошёл по 392 проверки без обрезаний в частичном режиме и режиме `full_refresh` с двумя полноэкранными буферами. Финальные OTA/browser/native/ESP32-P4 проверки и публикация успешны; все четыре публичных файла повторно скачаны без токена и сверены по SHA-256. [Отчёт выпуска и проверок](docs/verification/v0.10.3-ota-display-2026-11-05.md).

Установка v0.10.3 и физическое поведение LCD пока независимо не подтверждены. Исправление перерисовки включено и в v0.10.4. Скачивание исправления ещё рисует прежняя прошивка; новое поведение действует после запуска версии, которая его содержит.

## v0.10.2: температуры главной одним размером

Все четыре значения температуры на главном экране имеют одинаковый крупный размер — на дисплее 480×800 и во встроенном веб-интерфейсе. Температура топлива увеличена до размера остальных; канистра сохранена под числом и единицей измерения. В вебе сохранён прежний адаптивный размер крупных значений, а единица при нехватке места переносится на следующую строку. Исправление раскрытых карточек оборудования из v0.10.1 сохранено.

[v0.10.2 опубликована для GitHub OTA](https://github.com/DeadSoulf/boiler_room/releases/tag/v0.10.2) с успешными финальной сборкой, native LVGL, браузерными и профильными OTA/target проверками. До выпуска v0.10.3 её установка независимо не подтверждена. Исправление размеров температур включено и в v0.10.3. [Исторический отчёт выпуска](docs/verification/v0.10.2-ota-candidate-2026-11-05.md).

## v0.10.0: обновления из GitHub на панели

В **Настройки → Сервис → Обновление** добавлены поиск стабильного релиза, предложение конкретной версии, подтверждение установки, этапы и прогресс. Эти же действия доступны в сопряжённом веб-интерфейсе. Образ записывается в свободный раздел Flash с проверкой SHA-256, размера, платы/ревизии, разметки и загрузчика с откатом. Новая прошивка подтверждается после успешного запуска интерфейса и служб. Вставленная microSD используется для журнала событий; промежуточный образ и форматирование не нужны.

[Как обновлять панель и выпускать релизы](docs/github-ota.md). **v0.10.0 установлена и проверена 5 ноября 2026.** Первую версию с OTA установили через проверенный USB-пакет. Вход присутствия остаётся отдельной незавершённой задачей.

## Новое в v0.9.0

- В карточке «Топливо» на главной — небольшая температура и канистра. Отдельная нижняя кнопка уровня удалена. Полная / половина / пустая с «!»; неизвестные/устаревшие данные не заменяются полным баком.
- **Сопряжение начинается в браузере:** нажмите «Сопряжение». На дисплее автоматически открывается главная и появляется шестизначный код **слева от часов**. Экран при необходимости просыпается. После успешного ввода код исчезает; также исчезает при отмене или через 2 минуты. Раздел «Веб-доступ» на физическом дисплее удалён.
- Веб-интерфейс обновлён: Главная, Оборудование, Топливо, Настройки. Wi-Fi/BLE, часы, экран, датчики, Home Assistant и сервис сгруппированы внутри настроек. Технические сведения и опасные операции раскрываются отдельно.

Код сопряжения виден только на физическом дисплее, не передаётся в API или MQTT. Сессия длится час. Защита от повторных запросов/перебора не заменяет защищённую сеть: HTTP и MQTT этой версии **без TLS, только доверенная LAN, без проброса портов**.

## Герконы, датчики и управление

Для заданной пользователем схемы оба геркона настраиваются как **NC**: оба разомкнуты → полная; замкнут только верхний → половина; оба замкнуты → пустая с «!»; замкнут только нижний → ошибка уровня. Существующий режим NO сохранён для обратной полярности. Пины и NVS автоматически не меняются. Обрыв обычного несупервизируемого контакта неотличим от размыкания — не использовать этот индикатор как единственную защиту оборудования.

Доступны реальные входы DS18B20 и герконов на проверенных JP1 GPIO, четыре температурных и два уровневых канала. Пока реальные датчики не подключены/не испытаны. Нет команд силового управления котлами, насосами, реле и подогревом. Modbus/MQTT в конфигураторе входов ещё не являются работающими драйверами удалённых показаний.

Home Assistant получает 12 сущностей через MQTT Discovery; по умолчанию модуль выключен. Реальное подключение к брокеру ещё не проверялось. Веб-форма принимает пароль только локально и не возвращает его через API.
