# История изменений

## v0.10.4 — 2026-11-05

- На главной физической панели дата ДД.ММ.ГГГГ показана под временем в правом верхнем углу, в отдельной от кода сопряжения области.
- Время и дата читаются из одного момента времени с действующим часовым поясом. До установки часов обе строки показывают прочерки; дата обновляется при наступлении нового дня.
- Сохранены отдельный шестизначный код, крупные температуры, кнопка «Домой» на остальных страницах и исправление перерисовки OTA из v0.10.3. Изменения относятся к отображению на панели.
- v0.10.4 опубликована для GitHub OTA через PR #25 и проверенный release workflow. Native partial/full-refresh: по 408 проверок без обрезаний; профильные browser/OTA и target-сборка успешны, четыре публичных файла повторно скачаны и сверены. Аппаратная установка и физическая приёмка ожидаются. [Отчёт](docs/verification/v0.10.4-home-date-2026-11-05.md).

## v0.10.3 — 2026-11-05

- Устранено воспроизведённое на LVGL мигание кнопок страницы обновления: изменения RSSI больше не пересоздают страницу и не перезапускают анимацию недоступных кнопок.
- Неизменные подписи, доступность, прозрачность и видимость элементов не отправляются в повторную перерисовку каждые 100 мс; реальные изменения прогресса, объёма, этапа и подключения сохраняются.
- Добавлена регрессия на настоящем LVGL 8.3.11 в частичном и полном режимах обновления кадра; полный режим включён в профильный GitHub CI.
- v0.10.3 опубликована в GitHub; финальная target-сборка и профильные проверки успешны, четыре публичных файла повторно скачаны и сверены. Аппаратная установка и физическая проверка мерцания ожидаются. Предыдущая прошивка обслуживает само скачивание этого исправления; новое поведение действует после запуска v0.10.3.
- Добавлена штатная публикация проверенного OTA-кандидата через GitHub Actions по явному запросу конкретной release-веткой: нативные и браузерные проверки, target-сборка, проверка исходников/тега/файлов и повторное публичное скачивание с SHA-256. Публикация не отмечает версию установленной.

[Отчёт v0.10.3](docs/verification/v0.10.3-ota-display-2026-11-05.md).

## v0.10.2 — 2026-11-05

- Все четыре температуры главного экрана используют один крупный размер на физическом дисплее и в вебе; температура топлива увеличена до размера остальных.
- На панели единица °C вынесена под значение топлива, канистра пропорционально вписана ниже без пересечения со статусом уровня.
- В вебе снято отдельное уменьшение температуры топлива; единица измерения переносится при нехватке ширины, число остаётся целым.
- Проверки настоящего LVGL и браузерного стенда расширены для одинаковой типографики, отсутствия данных, отрицательных и трёхзначных показаний.
- Выпуск опубликован для GitHub OTA; все четыре файла повторно скачаны и сверены по SHA-256. Native LVGL: 384 проверки/0 обрезаний; Chrome: четыре ширины, 16 наборов значений, 28 опросов; финальная target-сборка и профильный CI успешны. Подтверждённая установленная версия пока v0.10.1, установка v0.10.2 ожидает штатного подтверждения. [Отчёт](docs/verification/v0.10.2-ota-candidate-2026-11-05.md).

## v0.10.1 — 2026-11-05

- Исправлено самопроизвольное сворачивание карточек «Оборудование» в веб-интерфейсе: периодический опрос обновляет значения без пересоздания раскрытых блоков и потери фокуса клавиатуры.

- Подготовка выпуска и аппаратная приёмка OTA разделены: публикация проверенной сборки перед первой сетевой установкой не объявляет её уже установленной.
- Выпуск опубликован в GitHub; все четыре файла повторно скачаны и сверены по SHA-256. **v0.10.1 установлена через GitHub OTA**, здоровая загрузка и возврат к v0.10.0 подтверждены по статусу устройства. Настройки и журнал microSD сохранены; проверка образа внутренняя, внешнего чтения Flash после OTA не было. [Отчёт](docs/verification/v0.10.1-ota-network-2026-11-05.md).

## v0.10.0 — 2026-11-05

- Обновление из стабильного GitHub Release: автоматическая проверка, предложение версии, ручное подтверждение, прогресс и отмена до переключения приложения.
- Страница обновления на физической панели и в сопряжённом веб-интерфейсе; привязка подтверждения к показанной версии и проверка результата после восстановления связи.
- HTTPS с CA bundle, ограниченные перенаправления, строгий манифест платы/ревизии/разметки, проверка размера/SHA-256 и образа ESP-IDF, запись только неактивного приложения.
- Подтверждение работоспособности после первого запуска, сторожевой срок и аппаратно совместимый загрузчик с откатом; ручной возврат к сохранённой предыдущей версии, когда она доступна.
- microSD пишет события через существующую службу журнала. Форматирование или хранение образа на карте не требуется.
- Выпуск содержит отдельный OTA-образ и манифест с исходным commit SHA; публикация latest выполняется после проверки полного набора файлов.
- Статус установки и границы аппаратной проверки фиксируются отдельным отчётом; вход присутствия в этот выпуск не включён.
- Установлено через USB 05.11.2026: новый полный backup v0.9.1, независимое штатное чтение всех 1 943 136 байт и HTTP подтвердили результат; настройки, загрузчик, разметка и microSD сохранены. [Аппаратный отчёт](docs/verification/v0.10.0-hardware-2026-11-05.md).

## v0.9.0 — 2026-11-04

- Карточка «Топливо»: небольшая температура и канистра, отдельная нижняя кнопка удалена (включает v0.8.1).
- Кнопка «Сопряжение» в браузере запрашивает одноразовый код на физическом дисплее слева от часов. Успешный ввод, отмена или истечение срока скрывают код. Раздел «Веб-доступ» удалён из меню дисплея.
- Запрос сопряжения привязан к случайному идентификатору браузера, ограничен по частоте и попыткам. Код не выдаётся через HTTP/MQTT; действующая сессия не отзывается простым запросом нового кода.
- Веб-дизайн: четыре основных раздела, канистра, вложенные настройки, компактные карточки оборудования и скрываемая диагностика. Сохранены формы сети, датчиков, часов, экрана, MQTT и защищённое форматирование microSD.
- Закреплён обязательный выпуск: установленный код в main, тег, GitHub Release, пакет/SHA-256 и актуальная памятка.
