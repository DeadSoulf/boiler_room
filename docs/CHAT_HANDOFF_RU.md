# Как мы работаем — памятка для нового чата

**Проект:** сенсорная панель котельной GUITION JC4880P443C_I_W, ESP32-P4 + ESP32-C6. **GitHub:** https://github.com/DeadSoulf/boiler_room, основная ветка `main`.

## Наш порядок работы

1. **Сначала восстанавливаем контекст**: читаем этот файл, [README_RU.md](../README_RU.md), [AGENTS.md](../AGENTS.md), актуальные коммиты, открытые Issues и PR. GitHub — основной источник кода и решений; сведения о состоянии панели проверяем отдельно.
2. **Работаем по-русски, последовательно и предметно.** Пользователь описывает задачу — ассистент самостоятельно проверяет код, вносит необходимые изменения, запускает подходящие тесты и сообщает результат. Уже известные данные повторно не спрашиваем; ошибки не скрываем.
3. **Не теряем чужие изменения.** Проверяем ветку и `git status`, не затираем незакоммиченные файлы на Asus. Для крупных доработок используем отдельную ветку/PR; после проверки и по запросу обновляем `main`. В GitHub фиксируем документацию, результаты и ограничения.
4. **Не смешиваем проекты.** Эта панель — отдельный проект; HEATER BENCH, PM02, экспериментальные ESP32-S3, HomeAiCore и другие контроллеры не переносим сюда без явного решения пользователя.
5. **Прошивка панели — только по явному запросу.** Панель подключается к компьютеру **Asus, COM3**; доступность соединения проверять заново. До записи — совместимость платы, хеши образа, загрузчик/разделы/OTA, полная локальная резервная копия текущего приложения. Пишем только нужный раздел, считываем обратно и проверяем. Не стираем NVS, ESP32-C6, microSD и другие разделы без отдельного согласования. Backup и секреты не публикуем в публичном GitHub.
6. **Никаких вымышленных данных и опасных команд.** Не изображаем датчик подключённым без реального измерения. Силовое управление котлами, отопителем, насосами и реле не включаем до согласования аппаратной схемы и защит.
7. **После каждого существенного этапа** обновляем код/тесты/README, фиксируем фактическую проверку и актуализируем эту памятку (версию, статус и следующие задачи). Если задача не завершена — пишем, что именно осталось.

## Где остановились

- **04.11.2026:** в `main` исходники **v0.6.2**; на физическую панель эта версия записана и проверена **03.11.2026**. Wi-Fi, веб-интерфейс и microSD работали на момент испытания.
- Веб-панель на момент проверки: `http://192.168.144.125/` (локальная сеть; IP может измениться).
- Есть четыре канала температур, два геркона топлива, защищённые назначения входов JP1 и меню устройств. **Реальные датчики ещё не подключены/не испытаны**; настройки входов пустые.
- Семь элементов отопительного оборудования отображаются как **«Контроллер не подключён»**. Modbus/MQTT пока конфигурационные поля, не рабочие драйверы; силовых команд нет.
- Общий CI требует исправить старые Wi-Fi/BLE host-моки: [Issue #15](https://github.com/DeadSoulf/boiler_room/issues/15). Отдельные safety-проверки успешны.
- Экспериментальные Neon/exFAT — [PR #10](https://github.com/DeadSoulf/boiler_room/pull/10), **не часть установленной v0.6.2**. exFAT не считать работающим драйвером.
- Подробное подтверждение прошивки: [аппаратный отчёт v0.6.2](verification/v0.6.2-hardware-2026-11-03.md). Подключение датчиков: [JP1 и DS18B20](real-sensors-v061.md).
