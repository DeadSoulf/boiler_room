# Аппаратная проверка Boiler Panel v0.6.2 — 3 ноября 2026

**Проект:** GUITION JC4880P443C_I_W, ESP32-P4 v1.3 (Flash 16 МБ) + ESP32-C6.
**Источник прошивки:** коммит [20056a61](https://github.com/DeadSoulf/boiler_room/commit/20056a61ae4baf6803c2367e6ad2c8f6d09cb46e), ветка разработки `release/boiler-panel-v0.6.2` на момент сборки. Начиная с 4 ноября этот коммит включён в `main`.
**Статус:** v0.6.2 установлена и отвечает по HTTP; физические входные датчики ещё не испытаны.

## Сборка и проверка

- Сборка на Asus из отдельного чистого клона GitHub: PlatformIO / PIOArduino 55.03.36-1, Arduino-ESP32 3.3.6, LVGL 8.3.11, BSP 324970b.
- PlatformIO для `jc4880p4`: **SUCCESS**. Размер `firmware.bin`: **1 608 224 байта**, SHA-256 `276d5041fb69dfb0babe0d58181564260a61bb5c171928c4d2fa4f1f14711986`.
- Установочный архив `BoilerPanel-v0.6.2-COM3.zip` сформирован на компьютере Asus, SHA-256 `9d75644fa9e66fabefbe974b180d947a9985932f882b1d6aeacb435236cdaf0e`. Архив и резервные копии хранятся локально: не публиковать содержимое Flash и конфиденциальные настройки в GitHub.
- Локально пройдены 18 защитных тестов `flash_panel_tests.py`, 7 тестов Windows launcher и проверки sensor/config/web/storage. Общий legacy CI пока **не зелёный** из-за несоответствия host-заглушек (`esp_wifi.h`) актуальному `panel_radio.cpp`; отдельные CI sensor/config/storage/web/launcher успешны.

## Запись на реальную панель

1. По COM3, 115200 бод проверены: ESP32-P4 v1.3, 16 МБ Flash, существующие загрузчик и таблица разделов, активный `app0` (адрес `0x10000`), OTA-запись.
2. Обнаружено допустимое исходное состояние ESP-IDF: первичная OTA-запись `seq=1` с CRC и вторая запись `seq=0` с оставшимися `0xFF`. Парсер исправлен только для точного формата; повреждённые CRC/состояния по-прежнему запрещены.
3. До записи сохранён полный старый `app0` (**6 553 600 байт**), загрузчик, таблица разделов и `otadata`. Их SHA-256 локально сверены.
4. Записано **только новое приложение в app0**. Первая автоматическая проверка побайтным чтением прервалась на USB (`Packet content transfer stopped` приблизительно на 10%); это не считалось успехом.
5. Отдельный вызов esptool повторно прочитал **все 1 608 224 байта** из Flash; SHA-256 и каждый байт совпали с исходным `firmware.bin`. Затем независимо прочитаны и сверены `partitions` и `otadata`.

Загрузчик, NVS, ESP32-C6, таблица разделов, OTA, SPIFFS и microSD установщиком **не записывались**. Не выполнялись `erase-flash`, перепрошивка C6 или автоматическое форматирование.

| microSD | `mounted=true`, `logging=true` |
| Каналы входов | 6, `revision=0`, назначений нет |
| Драйверы входов | `drivers_active=false` (пины не назначены) |
| Форматирование SD | `format_attempted=false` |
| Веб-интерфейс | прежний DEMO-текст отсутствует, «Управляющие выходы не подключены» присутствует |

Веб-адрес в момент испытания — `http://192.168.144.125/`; DHCP может его изменить. Веб работает только в доверенной локальной сети, без внешнего проброса HTTP.

**Не проверено физически:** измерение DS18B20 и герконов, сохранение назначений GPIO после сопряжения, управление отопительным оборудованием (в версии v0.6.2 управления нет). Нельзя считать успешную сборку или HTTP-проверку подтверждением реального управления.
