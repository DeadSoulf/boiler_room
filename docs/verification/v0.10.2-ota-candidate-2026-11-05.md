# v0.10.2 — одинаковый размер температур и выпуск через GitHub OTA

**Все четыре температуры главного экрана приведены к одному крупному размеру на панели и в веб-интерфейсе.** Сборка и проверки завершены. Выпуск опубликован для установки через GitHub OTA; на момент этого отчёта последняя подтверждённая установленная версия — **v0.10.1**. Публикация кандидата не считается его установкой.

## Изменение интерфейса

На физической панели 480×800 четыре числовых значения используют `boiler_font_55` и одинаковые координаты внутри карточек. Единицы °C находятся отдельно. Температура топлива увеличена; крупные значения остальных трёх температур сохранены. Канистра пропорционально размещена ниже числа и единицы; состояния, цвета, заливка и подпись уровня сохранены.

В вебе сняты отдельные уменьшенные размеры топлива. Все четыре значения используют одну адаптивную типографику. На проверенных ширинах размеры равны: 28 px на 320/390, 42 px на 768 и 39,68 px на 1280. Единица может переноситься при нехватке места, число остаётся цельным. Исправление раскрытых карточек оборудования из v0.10.1 сохранено.

Диапазоны датчиков, GPIO, настройки и управление оборудованием не изменялись. Действующие показания DS18B20 −55…125 °C, а также `--.-`, укладываются в крупное поле. Существующий защитный выбор меньшего шрифта для более длинной строки не срабатывает в этом поддерживаемом диапазоне.

CSS и прошивка при этом не менялись. Последующий полный прогон окончательного теста успешен. Метрики и снимки каждого случая сохраняются до assertions.

## Установка и границы проверки

Предыдущий этап v0.10.1 завершён: [сетевая приёмка](v0.10.1-ota-network-2026-11-05.md), [installed.json](installed.json). Дополнительная проверка перед выпуском v0.10.2 в 10:43:19 МСК показала v0.10.1 с uptime 1810 с, без pending/error, с предыдущей v0.10.0 и доступным возвратом. Приватный снимок настроек сохранён локально для сравнения после следующей установки. Контроль после публикации в 10:54:42 МСК всё ещё показал v0.10.1, uptime 2493 с, без ошибки; устройство ещё не выполнило новую проверку GitHub после выхода v0.10.2. Для получения нового предложения требуется штатная команда «Проверить».

Для установки новой версии: **Настройки → Сервис → Обновление → Проверить → подтвердить v0.10.2**. Те же команды доступны в обычной сопряжённой веб-сессии. Подтверждение конкретной версии и авторизация сохраняются; PIN не извлекается обходным путём.

USB-запись, перевод в ROM, форматирование microSD или изменение настроек для этого выпуска не выполнялись. До реального нового запуска v0.10.2, подтверждения boot и проверки HTTP/HTML/настроек её установка не объявляется завершённой. Физический осмотр дисплея, касания, реальные датчики, отключение питания и фактический rollback этим отчётом не подтверждаются.
