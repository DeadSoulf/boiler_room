# Boiler UI 2.0 Neon и поддержка exFAT — этап интеграции

## Статус
Эта ветка содержит **подготовку модели уровня топлива и технические требования**.
Она **не является готовой прошивкой с работающим exFAT**, не меняет
драйвер экрана или C6 и не предназначена для записи на панель до успешной сборки
и аппаратной проверки. Текущее приложение v0.4.0 продолжает показывать
«Нет данных» при отсутствии источника.

## Топливо
Два геркона преобразуются из физических входов в логические уровни после
настройки полярности, антидребезга и контроля исправности:
- сработал нижний: красный восклицательный знак внутри канистры («Низкий уровень»);
- сработал только верхний: половинное заполнение («Средний уровень»);
- ни один не сработал: полная канистра;
- входы не назначены/устарели: «Нет данных», без придуманного уровня.

Нижний сигнал имеет приоритет над верхним. Оба активны — показывать
«Низкий уровень» и отдельно логировать необычную комбинацию, а не скрывать
предупреждение. Обозначение 50% условное: два дискретных датчика не измеряют
фактические проценты. Перед интеграцией уточнить полярность и расположение
герконов, проверить эти положения на стенде.

## Визуальные эффекты
480×800 LVGL 8.3: тёмный графит, тонкая бирюзовая подсветка границ,
карточки с градиентами, канистра с уровнями заполнения, минимальные анимации.
Не использовать полноэкранное полупрозрачное размытие, большие тени и
постоянную перерисовку фона: они создают задержки на устройстве.
Переходы 120–180 мс, обновление показаний только при изменении.

## exFAT: аппаратный и программный план
exFAT — файловая система *внешнего блочного накопителя* (обычно SD/microSD).
Встроенная SPI NOR Flash с разделами ESP32 — не exFAT и не должна
переформатироваться. Необходимо подтвердить наличие SD-слота и линий
SDMMC/SPI, доступных для ESP32-P4 на конкретной ревизии JC4880P443,
а также исключить конфликты пинов с LCD, touch и радиомодулем.

Стандартный Arduino SD/FatFS не гарантирует поддержку exFAT.
После проверки SDK подключить совместимую лицензированную библиотеку
(например, SdFat с exFAT для SPI при подтверждённом совместимом хосте
и сборке), либо поддерживаемый exFAT-драйвер VFS для ESP-IDF.
Уточнить поддержку режима и версии в используемой платформе
pioarduino 55.03.36-1 / Arduino-ESP32 3.3.6 до компиляции.

Требования к безопасной реализации:
1. Опциональный флаг сборки, по умолчанию выключен; при отсутствии карты
   загрузка и LVGL работают штатно.
2. Монтирование только в отдельной фоновой задаче; короткие операции UI
   через очередь и снимок состояния, никаких синхронных открытий файлов
   из LVGL callback.
3. Режим только чтения на первом стендовом тесте; не форматировать
   носитель автоматически и не трогать NVS/отдельную Flash.
4. Контроль наличия и извлечения носителя, ограничение ожидания,
   проверки ошибок чтения, свободного места, защита путей и имён файлов.
5. Тесты с FAT32, exFAT, без карты и повреждённой картой;
   журнал ошибок без секретов.
6. Только после подтверждённой работы чтения — отдельное включение записи
   для журналов/истории с безопасным закрытием файлов.

## Установка
Никакой прошивки на COM3 эта ветка сама по себе не выполняет.
Запись возможна только после сборки и проверки соответствия рабочему BSP,
без erase-flash и без обновления C6; сохраните резервную копию.
