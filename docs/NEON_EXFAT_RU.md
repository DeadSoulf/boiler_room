# Boiler UI 2.0 Neon — v0.6.1-neon (ветка для проверки)

## Интерфейс LVGL
Главная страница (портрет 480×800): четыре карточки температур,
оттенки циана, тонкое свечение и градиенты без тяжёлой анимации,
векторная канистра, пояснение трёх состояний и три безопасных перехода
на страницу оборудования. Нижние кнопки навигации не используются.
Фактические показания не генерируются: при отсутствии датчиков остаётся
«Нет данных».

### Таблица индикации герконов
- Нижний сработал: красный «!» (низкий уровень).
- Только верхний: канистра наполовину (условное состояние, не точные 50%).
- Оба не сработали: полная канистра.
- Оба сработали: низкий уровень имеет приоритет.
- Нет свежих сигналов: «?», ничего не имитировать.

Таблица — заданная пользователем логика контактов, а не
электрическое подключение. Перед назначением GPIO нужно проверить
НО/НЗ контакт, направление сигнала, антидребезг и ошибки обрыва.
Команды силовой части не добавлялись.

## microSD и exFAT
Плата имеет SDMMC Slot0 (43 CLK, 44 CMD, 39-42 D0-D3), LDO4 3,3 В
включает рабочий BSP. Существующий драйвер v0.5.8 обслуживает FAT,
ведёт журналы в фоновой задаче. Новая диагностика пробует после ошибки
обычного монтирования прочитать только начальные секторы microSD:
VBR, MBR или начальную GPT-запись. Обнаруженная сигнатура exFAT
выводится в «Сервисе», данные не меняются.

ОГРАНИЧЕНИЕ: это распознавание exFAT, НЕ чтение файлов
и НЕ запись на exFAT. Настоящая поддержка чтения и записи требует
сборки FatFs с FF_FS_EXFAT=1 и согласованных структур FATFS/FIL в
ESP-IDF VFS; нельзя просто задать -D-флаг
к предварительно скомпилированной Arduino-библиотеке.
Запрещено форматирование карты с обнаруженной exFAT по веб-запросу.
Пока exFAT не смонтирован, журналирование приостановлено.

## Проверка и установка
Перед прошивкой нужна успешная сборка PIO для jc4880p4 на
pioarduino 55.03.36-1 и аппаратная проверка
первого кадра, GT911, свайпов, NVS, сети, SD без вмешательства
в C6 и стирания Flash. Обновление не следует устанавливать
поверх неизвестно изменённого BSP. Ветка/PR не устанавливают
прошивку автоматически.
