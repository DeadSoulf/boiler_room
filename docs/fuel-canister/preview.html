Канистра внутри карточки «Топливо»

Температура маленьким шрифтом над значком. Нижняя кнопка удалена.

Это отрисовка настоящего LVGL с тестовыми значениями, не данные устройства. Файл работает без сети и ничего не меняет на панели.

Для указанной схемы контактов оба входа используют режим NC: разомкнутый контакт = уровень достигнут. Пустая канистра с «!» отличается от неизвестных показаний с «?».
