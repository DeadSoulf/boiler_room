# Веб-интерфейс на панели JC4880P443 (v0.5.2)

В этом обновлении HTTP-сервер работает непосредственно на ESP32-P4. ESP32-C6 остаётся Wi-Fi-сопроцессором (ESP-Hosted 2.9.6), а не отдельным веб-сервером. Сервер запускается автоматически после подключения Wi-Fi и получения IPv4-адреса.

## Адреса

- `http://IP_ПАНЕЛИ/` — адаптивная русская панель мониторинга.
- `http://IP_ПАНЕЛИ/api/status` — JSON со статусами.
- `http://IP_ПАНЕЛИ/health` — ответ `ok` для проверки HTTP.

IP отображается на дисплее в **Настройки → Wi-Fi**; при USB-диагностике печатается строка `[BP-WEB] listening http://.../`.

Открывать адрес нужно с компьютера/телефона, имеющего сетевой доступ к панели. Если роутер включает изоляцию Wi-Fi клиентов, страница не откроется даже при успешном Wi-Fi-подключении панели.

## Данные

Четыре температуры (котельная, улица, теплоноситель, топливо), уровень топлива по двум герконам и семь карточек оборудования. Температуры и состояние топлива поступают из того же источника данных, что и LVGL-интерфейс. Пока реальные датчики не назначены, отображается «Нет данных», без генерации тестовых чисел.

Оборудование обозначено как локальная **ДЕМО**-модель. Веб-страница показывает только состояния демо. Фактическая работа устройств неизвестна, реальные выходы этой прошивкой не включаются.

Также доступны статус подключения Wi-Fi, IP, RSSI, версия панели, версии ESP-Hosted/C6, таймер подсветки и время работы.

## Безопасность

**Только наблюдение.** HTTP GET — единственный поддерживаемый метод, запросы не меняют Wi-Fi, время, реле, котлы, NVS и режимы оборудования. Никаких паролей, SSID или секретов в JSON и HTML нет.

Страница работает по HTTP без авторизации. Использовать **только в доверенной локальной сети**, не открывать порт 80 в интернет, не перенаправлять через роутер. Для удалённого защищённого доступа позже потребуется отдельная архитектура с аутентификацией.

## Проверка

После сборки и записи приложения на ESP32-P4 через COM3:
1. Убедитесь, что Wi-Fi подключён, получен IP.
2. Откройте `http://IP_ПАНЕЛИ/health` — должен быть `ok`.
3. Откройте `http://IP_ПАНЕЛИ/api/status` — должен быть JSON с `version`, `wifi.connected`, четырьмя `temperatures`.
4. Откройте `http://IP_ПАНЕЛИ/` — четыре карточки, статусы и список оборудования.
5. Перезагрузите панель, убедитесь в восстановлении Wi-Fi и HTTP.
6. Проверьте, что локальный интерфейс, свайпы и пробуждение касанием остались рабочими.

При проверке HTTP используйте только локальный адрес, не публикуйте сведения о домашней сети в открытом репозитории.

Этот веб-интерфейс не является GitHub OTA и не обновляет ESP32-C6.
