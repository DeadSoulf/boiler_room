# Панель котельной · Boiler Panel

Самостоятельный проект сенсорной панели GUITION JC4880P443 (ESP32-P4 ES v1.3, ESP32-C6, экран 480×800).

## Текущее обновление

Готовится v0.4.0: динамические карточки четырёх температур, навигация свайпами, настройки Wi-Fi/BLE, таймер отключения подсветки и пробуждение касанием. Реальные датчики и исполнительные выходы пока не назначены; отсутствующие измерения не заменяются демонстрационными значениями.

Исходники, подробная русская инструкция и GitHub Actions будут добавлены следующим коммитом. **Сборка v0.4.0 ещё не подтверждена.** Не используйте эту страницу как указание прошивать устройство сейчас.

## Зафиксированная конфигурация

- Arduino-ESP32 3.3.6, pioarduino 55.03.36-1, LVGL 8.3.11.
- Плата `jc4880p4`, вариант чипа `esp32p4_es`, CPU 360 МГц, `CORE_DEBUG_LEVEL=0`.
- Основной интерфейс и отдельный сервис C6 не смешиваются. Обновление C6 не входит в обновление меню.
- GitHub Actions выполняет проверки и сборку, но не прошивает панель.

## Безопасность установки

Не записывайте образ ESP32-C6 в ESP32-P4. Не стирайте память панели и не удаляйте рабочую резервную копию. Перед ручной установкой нужны успешная сборка конкретного коммита и подтверждение модели/порта. Успешная компиляция не заменяет проверку дисплея, касаний и Wi-Fi на устройстве.
